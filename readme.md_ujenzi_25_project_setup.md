# UJENZI 25 - Premium Construction & Property Platform

Huu ni mradi wa tovuti ya **Ujenzi 25** iliyoboreshwa kwa mtindo wa kisasa na rasmi (TRA Style). Mradi huu unajumuisha huduma tano kuu: Consultation, Construction, Real Estate, Rentals, na Hotels.

## Muundo wa Faili (File Structure)

Kila ukurasa umeandaliwa kwa HTML na Tailwind CSS. Kwa matumizi ya VS Code na GitHub, tumia mpangilio huu:

- `index.html` (Homepage)
- `about.html` (About Us)
- `services.html` (Consultation/Services Overview)
- `portfolio.html` (Our Projects)
- `contact.html` (Get in Touch)
- `request-consultation.html` (Form)
- `real-estate.html` (Listings)
- `admin-dashboard.html` (Internal management)

## Jinsi ya Kutumia kwenye VS Code
1. Pakua mafaili yote (HTML).
2. Fungua folder kwenye VS Code.
3. Tumia "Live Server" extension ili ku-preview mradi wako.
4. Push kwenye GitHub repository yako kwa ajili ya hosting (kama GitHub Pages).
